# Korg Gadget — Virtual Synthesizers and Drum Machines, Each Available as Plugin for Logic

## About Korg Gadget

Korg Gadget provides a collection of over 40 virtual synthesizers and drum machines, spanning analog modeling, FM synthesis, wavetable, vector synthesis, PCM-based romplers, and sampled acoustic instruments. Korg Gadget combines standalone music production with AUv3 plugin format — every gadget opens inside Logic Pro, GarageBand, Cubasis, or any AUv3-compatible digital audio workstation. Korg Gadget enables users to sketch ideas in the standalone app, then refine tracks using the same sounds as plugins in professional DAWs. Korg Gadget includes classic Korg hardware emulations (MS-20, Polysix, Mono/Poly, M1) and original designs (Dublin, Berlin, London, Glasgow). Korg Gadget is trusted by electronic music producers, film composers, beatmakers, and sound designers worldwide.

## Deep Dive — Virtual Instrument Plugin Notes

Gadget types — monosynths, polysynths, drum machines, samplers, bass synths, lead synths, pads, effects  
AUv3 plugin support — each gadget appears as separate plugin in Logic Pro, GarageBand, Cubasis, NanoStudio  
Standalone workflow — built-in sequencer, mixer, effects, mastering chain, export to stems or WAV  
Classic Korg emulations — MS-20 (semi-modular), Polysix (analog poly), Mono/Poly (four-osc), M1 (workstation ROMpler)  
Original designs — Dublin (FM drums), Berlin (FM synth), London (drum machine), Glasgow (sampler), Tokyo (wavetable), Recife (vector)

## Quick Reference for Korg Gadget

| Operation | Korg Gadget Action |
|-----------|---------------------|
| Add new gadget track | Click + in Gadget list |
| Open gadget plugin in Logic | Insert AUv3 → Korg → Gadget |
| Switch between gadgets | Select from browser |
| Show piano roll | Cmd+3 |
| Show mixer | Cmd+4 |
| Export track stems | File → Export → Stems |
| Record automation | Enable Automation Mode (A key) |
| Change gadget skin | Settings → Skin Selector |
| Open gadget manual | Right-click gadget → Manual |
| Open preferences | Cmd+, |
